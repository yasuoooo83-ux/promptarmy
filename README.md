# PROMPT ARMY 戦国版

自分の部隊への命令を**日本語**で書き、普段使っているAIに**ラテン語の軍令（JSON）**へ訳してもらい、中身を読まずに**封印**して提出する合戦ボードゲーム。
開戦後は全部隊が同時に動き、見守るだけ。合戦のあと、軍令を日本語に戻して**種明かし**する。

仕様書：`PROMPT_ARMY_戦国版_実装仕様書.md`（v0.1）。運営費0円（AIのAPI・Cloud Functions・有料サービスは使わない）。

## 遊ぶ（ローカルモード）

ES モジュールを使うので、ファイルを直接開かず、簡易サーバーで配信する。

```
cd public
python3 -m http.server 8000
# → http://localhost:8000/        （タイトルから「一人で試す」）
# → http://localhost:8000/?local  （陣立てから直接）
```

1. **陣立て**：両軍の編成（予算500・最大6部隊）と担当者名を決める。「おまかせ編成」もある。
   **布陣と道具**（作戦画面の上）：自陣の6列に部隊を置く（部隊の丸を押してからマスを押す）。道具（石垣・馬防柵・物見櫓・陣太鼓）を1つ選んで置く。置き終えたら「布陣と道具を封印」。
2. **作戦**：最初に「📜 早見表」と布陣。
   **基本命令**（選ぶだけ）：部隊ごとに「攻める／持ち場を守る／大将を守る／本陣を狙う」を選ぶ。これだけで開戦できる。
   **追加命令**（任意・AIで訳す）：工夫したい部隊にだけ、「10秒たったら突撃」「騎馬が近づいたら突け」のような時間・状況の条件つきの命令を日本語で書き、指示文をコピー→AIの返答を貼る→検査して封印。どの条にも当てはまらないときは基本命令で動く。ひとりで遊ぶときは「追加命令をまとめて書く」で1回のAI往復にできる。
3. **合戦**：30秒の合戦（1ターン＝1秒）。画面に残り秒数と進行バー。1秒送り・一時停止・速度変更・最後までができる。斜め上から見下ろした戦場に、兵アイコンの群れ（西は青、東は赤）が動く。接触すると前列が入り乱れる乱戦になり、矢の一斉射・鉄砲の白煙・騎馬突撃の弧・砂煙が出る。部隊の旗の上は兵力バー、横の丸数字は「いま動いている条」（中身は封印のまま）。各部隊が向かう相手は「進軍線」で見える（右上のボタンで表示を切り替え）。
4. **決戦**：30秒で大将も本陣も落ちなければ、両軍とも布陣の位置に戻り、失った兵の半分が戻る。そして、両軍が「全体指揮」（全部隊への号令）を1つずつ書いて封印し、最大15秒の決戦になる（急行軍で足が速い）。
5. **戦果**：勝敗と、軍ごとの「戦況レポート」。相手の作戦は明かさない。自軍のレポートを開いて「AIに相談するためにコピー」し、いつも使っているAIに「なぜこうなった？次はどうする？」と相談する。「作戦を直して再戦」で、作戦を引き継いだまま同じ条件（または新しい天候）でもう一度戦える。

タイトルの「デモ（命令入力済み・すぐ開戦）」または `http://localhost:8000/?demo` で開くと、全部隊に日本語の命令と軍令が入力済みの「作戦」画面から始まる（「開戦」を押すだけ）。作戦画面の「デモ（お試し用）」ボタンでも同じ入力ができる。

以前の説明：「作戦」画面の「動作確認用」を開くと、未封印の部隊に標準軍令を一括で入れられる（AIなしで合戦を試せる）。標準軍令は、歩兵（足軽・槍隊）は**半分が突撃・残りは守備**、騎馬は前進、弓・鉄砲はその場で射撃、大将は待機。

### 部隊を割合で分ける（v0.2）

行動に `"pars"`（1〜99）を書くと、「兵の○％だけがその行動、残りは守備」になる。例：`{"actio":"impetus","scopus":"proximus","pars":50}`。
その条が初めて働いたとき、部隊は二つに分かれる。`pars`％の兵（元の部隊）がその軍令に従い、残りは**守備隊**になって、その場を動かず来た敵と戦う（弓・鉄砲の守備隊は、その場から撃つ）。分かれるのは1回だけ。守備隊は戦果・種明かしでは元の部隊にまとめて表示される。

## 開発

必要なもの：Node.js 20 以上（動作確認は 22）。依存パッケージなし。

| 目的 | コマンド |
|---|---|
| テスト | `npm test`（= `node --test tests/*.test.mjs`） |
| バランス検証 | `node tools/balance.mjs 10000`（結果は `BALANCE.md` に記録） |
| 候補値の試行 | `OVERRIDE='{"stats":{"hastati":{"def":8}}}' node tools/balance.mjs 2000` |
| AI翻訳の合格率 | `node tools/check-orders.mjs W3 equites out/*.txt` |
| 決定論の自己診断（Node） | `node tools/hash.mjs` |

### 決定論のチェック（ブラウザ間）

合戦は各自のブラウザで計算するので、どのブラウザでも結果が同じでなければならない。
`node tools/hash.mjs` の3行と、各ブラウザで `public/hashcheck.html` を開いたときの3行が**一致**することを確認する（Chrome・Edge・Firefox・Safari）。
エンジンを意図して変えたときは `ENGINE_VERSION` を上げ、`tests/golden.test.mjs` の値を更新する。

### フェーズ2の完了条件を確かめる手順

1. ローカルモードで部隊の「指示文をコピー」を押し、ChatGPT・Gemini・Claudeのうち2つ以上に貼る。末尾に日本語の命令を書いて送る。
2. 返答を1回ずつ `out/gemini-01.txt` のように保存する（コードブロック付きのままでよい）。各AIで10回ずつ。
3. `node tools/check-orders.mjs W3 equites out/gemini-*.txt` で合格率を見る。9割未満なら、表示された「読めなかった語」を `public/js/engine/vocab.js` の `SYNONYMS` に足す。

### エンジンの約束

- 整数演算のみ。割り算は必ず切り捨て（符号のある値は `Math.trunc` で、東西の点対称を保つ）。`Math.random`・`Date` は使わない。平方根は整数の `isqrt`（浮動小数の誤差を補正）。
- 位置は連続座標（1マス=100の整数）。部隊は小歩（25）ずつ同時に進み、近すぎる部隊は押し合って間隔（70）を保つ。
- 乱数は自前のシード付き整数乱数（mulberry32）。
- 走査順は部隊の ord（スロット番号順、同番号は西軍が先）に固定。同時解決を徹底。
- 同点の選び方は東軍で点対称に反転（左右の有利不利を作らないため）。
- 距離はユークリッド距離。「距離n」は n×100+20 以内。近接は 120 以内、弓は 320、鉄砲は 220（丘の上は +100）。
